# JuanEnPruebas — sitio web

Sitio estático para GitHub Pages. Proyecto personal sobre videojuegos, opiniones, análisis y experimentos con datos.

## Archivos
- `index.html`: portada
- `sobre-mi/index.html`: biografía y enfoque
- `opiniones/index.html`: índice de opiniones
- `analisis/index.html`: índice de análisis
- `experimentos/index.html`: índice de experimentos
- `styles.css`: estilos compartidos
- `script.js`: pequeñas mejoras progresivas

## Publicación
Configuración de GitHub Pages: Deploy from a branch → `main` → `/(root)`.

## Antes de lanzar públicamente
- Revisa la biografía y decide qué datos personales quieres mostrar.
- Añade enlaces correctos a redes y comunidad.
- Cuando se compre un dominio, actualiza las etiquetas canonical y añade `CNAME`.
- Añade sitemap.xml y robots.txt con la URL definitiva.
- Publica solo métricas y afirmaciones verificadas.
